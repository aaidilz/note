# ANY.RUN Registration Guide

## Link
https://app.any.run/#register

## Tentang ANY.RUN
ANY.RUN adalah platform sandbox interaktif berbasis web yang digunakan untuk analisis malware dan phishing secara real-time dalam lingkungan virtual yang aman.

## Fungsi Utama
- Analisis file atau URL mencurigakan
- Observasi perilaku malware secara langsung
- Interaksi dengan sistem virtual (VM)
- Mendapatkan laporan seperti:
  - Process activity
  - Network connections
  - IOC (Indicators of Compromise)

## Cara Register
1. Buka link registrasi:
   https://app.any.run/#register
2. Isi data:
   - Email
   - Password
3. Verifikasi email (jika diminta)
4. Login ke dashboard

## Catatan
- Versi gratis tersedia dengan keterbatasan
- Session public (hasil analisis bisa dilihat orang lain)
- Mode private hanya tersedia di plan berbayar

## Use Case
- Malware analysis
- Reverse engineering dasar
- Threat intelligence
- Belajar cyber security secara praktikal

## Kelebihan
- Interaktif (bisa klik, buka file, dll)
- Tidak perlu setup VM sendiri
- Cepat (analisis dalam hitungan menit)

## Kekurangan
- Free tier terbatas
- Resource VM terbatas
- Session bisa dipublikasikan
